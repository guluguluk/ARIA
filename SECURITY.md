# Security Policy

## Supported Versions

ARIA is currently under active development.

Security fixes will generally be made against the latest version of ARIA.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability in ARIA, please **do not report it publicly in a GitHub Issue or Discussion**.

Please use GitHub's **private vulnerability reporting** feature, if enabled for this repository.

If private vulnerability reporting is unavailable, please contact the maintainer privately before publicly disclosing the vulnerability.

When reporting a vulnerability, please include:

- A description of the vulnerability
- Steps to reproduce it
- The potential impact
- Any relevant logs, screenshots, or proof-of-concept information
- A suggested fix, if you have one

Please do not include API keys, passwords, tokens, or other sensitive information in a public issue or discussion.

## Responsible Disclosure

Please give the maintainers reasonable time to investigate and address a vulnerability before publicly disclosing it.

We appreciate responsible security research and will do our best to investigate reported vulnerabilities and release fixes when appropriate.

Thank you for helping keep ARIA and its users safe. 🔐
