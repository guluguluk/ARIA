# Contributing to ARIA

First of all, thank you for wanting to contribute to **ARIA**! 🤖

ARIA is an open-source project, and contributions from the community are welcome. Whether you're fixing a bug, improving documentation, suggesting an idea, or adding a feature, every contribution can help make ARIA better.

## 💡 Ways to Contribute

You don't have to write code to contribute!

You can:

- 🐛 Report bugs
- 💡 Suggest features or improvements
- 📖 Improve documentation
- 🧪 Test ARIA and report your experience
- 🔧 Fix bugs or improve existing code
- 🚀 Add new features
- 🤝 Help other community members in Discussions

## 🐛 Reporting Bugs

Before opening a bug report:

1. Check whether the issue has already been reported.
2. Make sure you're using the latest version of ARIA.
3. Provide as much useful information as possible.

When reporting a bug, please include:

- What happened
- What you expected to happen
- Steps to reproduce the problem
- Your operating system
- Relevant error messages or logs

Please **do not post API keys, passwords, tokens, or other sensitive information** in an issue or discussion.

## 💡 Suggesting Features

Have an idea for ARIA?

You're welcome to open a feature request or start a Discussion.

Explain:

- What you'd like to see
- Why it would be useful
- How you imagine it could work

Ideas don't have to be perfect. Discussions are encouraged! 💬

## 🔧 Contributing Code

If you'd like to contribute code:

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Commit your changes with a clear message.
6. Push your branch to your fork.
7. Open a Pull Request.

Please keep Pull Requests focused on one feature, fix, or improvement whenever possible.

## 🔀 Pull Requests

Before submitting a Pull Request:

- [ ] My changes work as expected.
- [ ] I have tested my changes.
- [ ] I have not included API keys, passwords, or other secrets.
- [ ] I have updated documentation where necessary.
- [ ] My changes are relevant to the purpose of the Pull Request.

Please explain **what your Pull Request changes and why**.

Maintainers may request changes, ask questions, or suggest improvements before merging.

## 🤝 Community

Please be respectful and constructive when interacting with other contributors.

For more information, see our [Code of Conduct](CODE_OF_CONDUCT.md).
